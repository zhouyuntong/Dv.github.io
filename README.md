# 贪吃蛇游戏

一个使用原生 HTML、CSS 和 JavaScript 开发的经典贪吃蛇游戏。

## 项目结构

```
.
├── index.html          # 主页
├── snake.html          # 贪吃蛇游戏页面
├── css/
│   └── snake.css       # 游戏样式
├── js/
│   └── snake.js        # 游戏逻辑
└── README.md           # 项目说明
```

## 功能特点

- 🎮 经典贪吃蛇玩法
- 🏆 最高分记录（本地存储）
- 🎨 现代化 UI 设计
- ⚡ 逐渐加速机制
- ⏸️ 暂停/继续功能
- 💀 碰撞检测（墙壁和自身）

## 操作说明

- **方向键** ↑ ↓ ← → 或 **WASD** 控制蛇的移动
- 吃到食物可以得分并变长
- 撞到墙壁或自己就会游戏结束
- 随着得分增加，蛇的移动速度会逐渐加快

## 如何开始

1. 在浏览器中打开 `snake.html` 文件
2. 点击"开始游戏"按钮
3. 使用键盘控制蛇移动

## 技术架构

### CSS (css/snake.css)
- 响应式布局
- 渐变背景效果
- 动画过渡效果
- 现代化组件样式

### JavaScript (js/snake.js)
采用面向对象的设计模式：

- **CONFIG** - 游戏配置常量
- **GameState** - 游戏状态管理
- **GameRenderer** - 渲染器，负责绘制游戏画面
- **SnakeGame** - 游戏控制器，核心逻辑
- **UIController** - UI 控制器，处理界面更新

## 代码重构说明

本次重构将原始的单文件代码分离为：
1. **HTML** - 只保留结构 markup
2. **CSS** - 所有样式提取到独立文件
3. **JavaScript** - 使用类（Class）组织代码，提高可维护性和可扩展性

重构后的优势：
- ✅ 代码职责分离，易于维护
- ✅ 面向对象设计，便于扩展
- ✅ 配置集中管理，方便调整
- ✅ 注释清晰，代码可读性强
